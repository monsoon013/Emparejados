# VIDEOJUEGO EMPAREJADOS
Cuadrícula de cartas para emparejar. Juego de memoria. 
## Tiene que contener:
    - Nombre de usuario
    - Puntuación
    - Recuento de errores
    - Tiempo máximo de un minuto
    - Tablero 6 x 5

## Normas
    - Desde el primer click, comienzo la cuenta atrás.
    - Si termino el juego ANTES de que se acabe el tiempo, sumo +40 a la puntuación
    - Solo son visibles con cada acierto de pareja
    - Si se acaba el tiempo que aparezca un modal que indique Game Over y los datos

## Requisitos
    · Pantalla inicial
        - TOP 5: Los datos de los jugadores se van a una base de datos, ordenados de mayor a menor puntuación -> Conectar la bd para que muestre el top 5
        - Botón de jugar
    · Pantalla de juego
    · Introduce nombre de usuario al darle al botón de jugar

## Tecnologías
    - HTML5, CSS, JS, PHP + MongoDB Atlas
